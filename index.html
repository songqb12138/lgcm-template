一份自包含、可复现的 R 模板，演示如何用多组潜增长曲线模型分析纵向结果按分组分层的四年轨迹。

这是什么

一个完整的分析流程脚本（lgcm_template.R），覆盖：清洗 → 复合结果（Y）→ 多组潜增长 → 测量不变性完整链 → Satorra–Bentler 比较 → 协变量调节 → 增长形态检验 → 轨迹图。数据与全部代码均可复现运行。

两处"正确示范"（市面教材常讲错）

  • 测量不变性要走到 scalar：跨组比较潜均值的前提是至少 scalar（强）不变性，而非 strict。模板完整呈现 configural → metric → scalar → strict 四级链，并标出不变性究竟在哪一级失效。
  • 增长形态要检验：用缩放 LRT 比较线性与二次模型，避免"默认线性"掩盖非线性轨迹。

怎么用

  • 安装依赖：lavaan / semTools / dplyr / ggplot2
  • 在 R / RStudio 中运行：source("lgcm_template.R")

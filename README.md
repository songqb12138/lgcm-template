# LGCM Reproducible Template — Longitudinal Outcomes by Group

## 这是什么 / What this is
一份**自包含、可复现**的 R 模板，演示如何用**多组潜增长曲线模型（MG-LGCM）**分析四年纵向结果按分组分层的轨迹。本模板配套 **100% 合成数据**（不含任何真实记录），目的是把整条分析流程跑通、便于教学与二次开发。

> **关于数据格式的重要说明**：免费模板里的合成数据**刻意使用通用占位变量名**（`grp` / `cov` / `y_1..y_4` / `z_1..z_4`），只演示流程结构，**不暴露任何真实研究的数据格式**。真正可用于你自己数据的「生产级数据格式规范 + 真实样例数据集」在本模板的 **¥5 增值包** 中（见文末）。

## 数据声明（务必先读）
- 本模板使用的 **100% 为合成数据**（`simulate_data()` 生成），仅复现一项通用纵向研究的**整体结构**（分组 + 协变量 + 重复测量），**不含任何真实记录**，数值均为虚构。
- 要用你自己的数据：把 `simulate_data()` 替换成你的数据读取函数，下游流程无需改动（详见脚本第 9 节）。**你数据的真实格式与一份可运行的样例，见付费包。**

## 两处方法学补强（最佳实践示范）
本模板在两点上刻意做得比"直接拟合并报告"更严谨，作为方法示范：

1. **测量不变性完整序列（configural → metric → scalar → strict）**
   跨组比较潜均值的前提是**至少 scalar（强）不变性**。规范做法应逐步报告整条链，因为 scalar——而非 strict——才是潜均值可比性的真正前提（即便 strict 不成立，只要 scalar 成立，潜均值仍可比）。第 4 节以 `cfa()` + `group.equal` 手动完整呈现四级链条与每一步的缩放 ∆χ²，便于看清不变性究竟在哪一级失效。在随附样例（付费包中的真实样例数据集，seed 20260621）上：scalar 不成立（某指标组间截距本就不可比），恰说明为何不可直接比较该指标的潜均值 —— 具体数值见付费包示例输出。

2. **线性 vs 二次增长对比**
   四年窗口内轨迹可能呈 **V 形/非线性**。固定载荷 0/1/2/3 强设线性可能掩盖这一形态。第 6 节用缩放 LRT 比较线性与二次模型。在随附样例上，二次不显著、线性充分 —— 具体数值见付费包示例输出。

> 这两点体现方法学严谨性：完整不变性链 + 增长形态检验，而非泛化代码。免费模板用通用占位数据跑通同一套流程；**可复现的数值结果以付费包样例为准**。
